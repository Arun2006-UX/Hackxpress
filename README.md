## ✨ Our Solution

- 🤖 **Aggregates** all obligations across channels

- 🔔 **Reminds** you proactively via multiple channels
- 💡 **Learns** from your patterns
- 📈 **Predicts** upcoming obligations
- 🎯 **Automates** recurring workflows

## 🎮 How to Use

### Quick Start
1. **Open the application:**
   - Download `index.html`
   - Open in any modern browser (Chrome, Firefox, Safari, Edge)
   - No installation needed!

2. **Add your first obligation:**
   - Click **"+ Add Obligation"** button
   - Select type (Bill, Insurance, Maintenance, etc.)
   - Fill in details (title, due date, amount)
   - Click **"Add Obligation"**

3. **Set reminders:**
   - Go to **Reminders** section
   - Configure preferred notification channels
   - Set reminder timing (1 day, 3 days, 1 week, etc.)

4. **Track progress:**
   - Monitor **Health Score** on dashboard
   - Review **Analytics** for spending insights
   - Check **Timeline** for upcoming deadlines
